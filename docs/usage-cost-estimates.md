# 用量费用估算与缺价恢复

官方价格预设首批覆盖 DeepSeek 官方 deepseek-flash 和阿里云百炼北京、新加坡 qwen3-asr-flash / qwen3-asr-flash-filetrans。只匹配官方服务地址与模型组合的完整哈希，不把代理服务上的同名模型套用官方价。自定义价格优先，显式零价表示免费，全空的自定义模型项表示尚未配置；删除该模型覆盖项可恢复预设。

参考价格核对日期：2026-11-03。费用为原价估算，不含赠送额度、阶梯优惠、账号折扣等实际账单因素。

- DeepSeek：按请求时间在北京时间选择高峰/空闲价格，缓存命中与未命中输入分开计算。2026 节假日使用国务院安排；周末即使调休上班仍按供应商“周一至周五”的规则处理。该日历只覆盖2026，其他年份保持未知，需维护预设或设置自定义价格。缓存写入计入普通未命中输入一次，不额外重复收费。
- Qwen3 ASR：官方每音频秒单价换算成内部每分钟微元费率；音频时长乘单价，不再叠加返回的文字 Token。北京0.00022元/秒，新加坡0.00026元/秒。

后台“模型与语音 → 费用估算单价”显示官方/自定义来源、参考版本及官方文档链接。手动修改保留原有精确微元和并发版本检查。恢复官方价格只移除当前模型的覆盖项，不删除其他模型（包括已停用模型）的价格。

## 历史补算

`POST /admin/api/usage-pricing/backfill` 仅服务器 owner 可调用，保留管理员会话、同源与 CSRF 检查。请求包含 `expected_revision`、`expected_config_revision` 和可选 `cursor:[user_id,request_id]`。

每批至多扫描500条无价格快照的记录，响应包含 scanned / updated / skipped / next_cursor。后台一次最多20批，并保留游标以便继续；每批使用同一价格版本。价格版本变化时拒绝继续，不覆盖已经完成的批次。数据库事务锁定价格版本，不依赖 HTTP 客户端锁保证一致性。

只补算已有足够计费用量且能匹配单价的记录，保留 request_id、用户、用量和已有价格快照。重复执行不会重复修改已补算的记录。未完成请求和未知供应商保持原样；用量到齐或补全价格后可以重试。重建的价格版本标记 reconstructed，而非冒充当时真实扣款。

手机费用接口增加可选的缺价格次数、缺完整计费用量次数、参考价补算次数；客户端兼容旧服务器，并分别提示具体原因。补算不需要修改表结构。
