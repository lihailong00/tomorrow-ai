# 支付宝、百度网盘与印象笔记

这三个入口位于“能力 → 我的连接”。原有个人 MCP、通知和资料导入功能保留。

## 支付宝：待配置入口

用户已确认尚未开通支付宝正式移动端 Agent Pay 接入，本版只保留待配置卡片、状态查询与官方说明链接。绑定、开通和校验接口明确返回 `wallet_not_configured`；不收集或保存绑定码，不创建钱包，不付款，也不会使用运营者账号代替用户。

支付宝的办公 Agent CLI 与移动端平台接入是不同路线。官方移动端平台文档要求企业邀请、签约与对应 API/SDK；办公 CLI 没有已验证的多用户命名空间契约，改变 HOME 不能证明远端钱包身份隔离。本版没有把办公 CLI 或安装辅助器打包进服务器，也没有伪装成其他 Agent。未来取得正式接入资格后，需单独实现并验收用户授权和身份隔离，不能靠一个开关假启用。

## 百度网盘：个人体验

使用百度网盘官方 MCP 的个人 Access Token。用户从官方仓库说明中的授权链接完成授权，获取自己的 Token 后在客户端填写。令牌属于本人，不在管理员后台填写或共用。

官方当前标明个人授权为测试体验，不应用于正式环境；正式接入应按百度开放平台要求申请。服务默认关闭，管理员可在“后台 → 应用连接”中启用 **百度网盘个人体验（仅限测试，非正式环境）**，对应设置 `BAIDU_NETDISK_EXPERIENCE_ENABLED=true`。这不是绕过服务商的开通条件，用户账号仍需拥有有效的官方授权。

连接采用官方固定旧版 SSE 地址，不接受用户自定义服务地址。建立连接、初始化和工具发现后，还会实际调用只读 `user_info` 校验账号，不能仅凭工具列表就显示已连接。服务端下发的消息端点限于同源安全地址，禁止重定向和跨站转发 Token。

界面和凭证环境均标为 `experience`，不会显示为正式环境。关闭后台体验开关后停止使用连接。写入和其他未确认只读性质的工具仍需本人在客户端确认；不会在绑定过程中操作真实文件。

## 印象笔记：官方 Skill 接口适配

使用官方 Skill v1.0.4 的固定 HTTPS 接口，属于官方 Skill 适配，不冒充厂商原生 MCP 服务。官方授权页为 <https://app.yinxiang.com/third/skills-oauth/>，目前需要印象笔记会员才能生成个人 AuthToken。

填写个人 AuthToken 后，后端实际请求笔记本列表验证权限；明确返回成功且结构有效才保存为已连接。没有调用账户信息接口，也不会使用社区旧版 Developer Token 代替官方 AuthToken。

支持笔记本列表、标签列表、笔记搜索、笔记列表、笔记正文，以及经本人确认后创建/更新笔记、创建笔记本和标签。首版没有开放异步网页剪藏，避免把提交成功误报为已完成剪藏。

与其他个人连接相同，凭证、工具缓存和待确认操作按用户加密隔离；客户端不持久保存 Token，换号/换服时清空表单并中断旧请求，断开不会让在途结果恢复旧连接。

## 验证边界

测试使用本机可控上游、会话和模拟器，不使用真实会员 Token，不开通真实支付宝钱包，不付款、不修改用户的真实网盘文件或笔记。正式个人账号的正向互通仍需账号持有人自行授权后验证。云端发布与本机代码验收分开记录。
